# Ecosystem Apps

Tools and services built around DecentralChain.

| App | What it does |
|---|---|
| [Decentral.Exchange](https://decentral.exchange/) | Decentralized exchange and web wallet: create accounts, hold and trade tokens |
| [DecentralScan](https://decentralscan.com/) | Block explorer: browse blocks, transactions, accounts and tokens |
| [Testnet faucet](https://testnet.decentralscan.com/faucet) | Free Testnet DCC for development and testing |
| [Cubensis Connect](https://github.com/Decentral-America/cubensis-connect) | Browser-extension wallet that lets dApps request signatures without ever seeing a seed; see {doc}`Wallet Integration <04_building-apps/04_wallet-integration>` |
| [DecentralChain IDE](https://decentralchain-ide.com/) | Browser IDE for writing and testing Ride; see {doc}`Developer Tools <04_building-apps/01_developer-tools>` |

Testnet tokens have no value. Use the faucet with a Testnet address (chain ID `!`, addresses starting `31`), as described in {ref}`Mainnet, Testnet <02_decentralchain/08_mainnet-testnet-stagenet:Network Parameters>`.
